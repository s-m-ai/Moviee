🎬 อัปโหลดวิดีโอ → ลิงก์ .mp4

ลากไฟล์วิดีโอมาวาง หรือคลิกเพื่อเลือกไฟล์ แล้วรับ direct URL พร้อมปุ่มดาวน์โหลดและโค้ดฝัง — ประมวลผลในเบราว์เซอร์ 100% ไม่มีการส่งไฟล์ขึ้นเซิร์ฟเวอร์

หมายเหตุ: ลิงก์ที่ได้เป็น blob: URL ซึ่งชี้ไปยังไฟล์ในหน่วยความจำของเบราว์เซอร์นี้ — ใช้งานได้ทันที (เปิดแท็บใหม่ / ดาวน์โหลด / ฝังในหน้าเว็บ) แต่จะใช้ได้เฉพาะในเบราว์เซอร์และแท็บนี้เท่านั้น เมื่อปิดแท็บ ลิงก์จะหมดอายุ และไม่สามารถแชร์ให้ผู้อื่นเปิดได้ หากต้องการลิงก์ .mp4 ถาวรที่แชร์ได้จริง ต้องอัปโหลดไฟล์ขึ้นโฮสต์จริง เช่น GitHub Releases, Cloudflare R2, Amazon S3 หรือ Supabase Storage (GitHub Pages เป็น static hosting ที่ไม่รับการอัปโหลดไฟล์)
